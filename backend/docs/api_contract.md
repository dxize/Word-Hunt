# API Contract — Word Hunt

### 1. Получение карточек и поиск по английскому слову

| Поле                  | Значение                                                              |
| --------------------- | --------------------------------------------------------------------- |
| **Действие**          | Получить список всех карточек или найти карточки по английскому слову |
| **Метод**             | `GET`                                                                 |
| **URL**               | `/cards`                                                              |
| **Query**             | `word` — необязательный параметр: введённое слово или его начало      |
| **Request Body**      | Отсутствует                                                           |
| **Успешный ответ**    | `200 OK`, JSON-массив карточек                                        |
| **Ничего не найдено** | `200 OK`, пустой массив `[]`                                          |
| **Ошибка сервера**    | `500 Internal Server Error`                                           |

**Логика работы:**

- Если `word` отсутствует — возвращаются все карточки.
- Если `word` передан — выполняется поиск по началу слова без учёта регистра.

### 2. Создание новой карточки

| Поле                    | Значение                               |
| ----------------------- | -------------------------------------- |
| **Действие**            | Создать новую карточку                 |
| **Метод**               | `POST`                                 |
| **URL**                 | `/cards`                               |
| **Query**               | Отсутствуют                            |
| **Request Body**        | Слово, перевод, пример использования   |
| **Успешный ответ**      | `201 Created`, JSON созданной карточки |
| **Дубликат**            | `409 Conflict`                         |
| **Некорректные данные** | `422 Unprocessable Content`            |
| **Ошибка сервера**      | `500 Internal Server Error`            |

### 3. Редактирование существующей карточки

| Поле                    | Значение                                 |
| ----------------------- | ---------------------------------------- |
| **Действие**            | Редактировать существующую карточку      |
| **Метод**               | `PATCH`                                  |
| **URL**                 | `/cards/{id}`                            |
| **Параметры**           | `id` — уникальный идентификатор карточки |
| **Request Body**        | Только изменяемые поля карточки          |
| **Успешный ответ**      | `200 OK`, JSON с обновлённой карточкой   |
| **Карточка не найдена** | `404 Not Found`                          |
| **Дубликат**            | `409 Conflict`                           |
| **Некорректные данные** | `422 Unprocessable Content`              |
| **Ошибка сервера**      | `500 Internal Server Error`              |

### 4. Удаление существующей карточки

| Поле                    | Значение                                 |
| ----------------------- | ---------------------------------------- |
| **Действие**            | Удалить существующую карточку            |
| **Метод**               | `DELETE`                                 |
| **URL**                 | `/cards/{id}`                            |
| **Параметры**           | `id` — уникальный идентификатор карточки |
| **Request Body**        | Отсутствует                              |
| **Успешный ответ**      | `204 No Content`                         |
| **Карточка не найдена** | `404 Not Found`                          |
| **Некорректный ID**     | `422 Unprocessable Content`              |
| **Ошибка сервера**      | `500 Internal Server Error`              |
